# Knitting Chart Marker

A simple browser-based PDF viewer for highlighting rows in knitting charts.

## Features

* Open knitting chart PDFs directly in the browser
* Move the horizontal row marker one row at a time
* Adjust the marker height and position
* Change the marker color
* Add one or two draggable vertical markers
* Control the row marker with keyboard arrow keys
* Works on desktop and iPad

## Keyboard Controls

* Left Arrow: Move the row marker down
* Right Arrow: Move the row marker up

No files are uploaded to a server. PDFs are opened locally in your browser.
